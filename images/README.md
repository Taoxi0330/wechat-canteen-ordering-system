# 图标文件说明

## TabBar图标要求

微信小程序TabBar图标需要满足以下规格：
- 图片格式：PNG
- 图标尺寸：81px × 81px（推荐）
- 文件大小：不超过40KB
- 图标风格：建议使用线性图标，简洁明了

## 需要的图标文件

### 1. 首页图标
- `home.png` - 普通状态的首页图标（房子/主页图标）
- `home-active.png` - 选中状态的首页图标（蓝色 #409eff）

### 2. 食堂图标  
- `shop.png` - 普通状态的食堂图标（店铺/餐厅图标）
- `shop-active.png` - 选中状态的食堂图标（蓝色 #409eff）

### 3. 购物车图标
- `cart.png` - 普通状态的购物车图标
- `cart-active.png` - 选中状态的购物车图标（蓝色 #409eff）

### 4. 订单图标
- `order.png` - 普通状态的订单图标（订单列表/文档图标）
- `order-active.png` - 选中状态的订单图标（蓝色 #409eff）

### 5. 个人中心图标
- `profile.png` - 普通状态的个人图标（用户头像/人物图标）
- `profile-active.png` - 选中状态的个人图标（蓝色 #409eff）

## 其他需要的图标

## 设计建议

1. **颜色规范**：
   - 普通状态：#666666 或更淡的灰色
   - 选中状态：#409eff（主题色）

2. **风格统一**：
   - 使用线性图标风格
   - 保持图标粗细一致
   - 圆角设计，现代简洁

3. **可访问性**：
   - 图标含义清晰
   - 与文字标签相符
   - 在不同背景下都能清晰显示

## 创建工具推荐

- [Iconfont](https://www.iconfont.cn/) - 阿里巴巴矢量图标库
- [Feather Icons](https://feathericons.com/) - 简洁的线性图标
- [Figma](https://www.figma.com/) - 在线设计工具
- [Sketch](https://www.sketch.com/) - Mac平台设计工具

## 注意事项

1. 确保图标文件路径与 `app.json` 中配置的路径一致
2. 图标文件名区分大小写
3. 建议使用SVG转PNG以确保图标清晰度
4. 测试不同设备上的显示效果
